Como instalar e configurar o oksh no Linux
@ Pedro Portales | Sábado, 3 de Abril de 2021 | 4 minutos de leitura | Atualizado Sábado, 3 de Abril de 2021

O bash costuma ser o shell mais conhecido no mundo linux por vir padrão na maioria das distros. Muitos as vezes se perguntam: Será que existe algum outro shell para linux? Se tem, como posso instalá-lo? São essas perguntas que vamos responder nesse artigo!

Existem tantos shells que é até difícil saber os nomes de todos eles! Porém, os mais conhecidos são o bash, o zsh, e o fish. Ainda assim, existem diversas pessoas que preferem um shell mais minimalista… Eu diria que o oksh é uma ótima opção! Hoje, vamos ver como podemos instalar e configurar o oksh!

Instalando o oksh via repositório

É importante lembrar de instalar antes de configurar! Como eu estou usando o Arch, utilizarei o AUR (Arch User Repository) e o yay como auxiliar do AUR (AUR helper) para exemplificar o processo de instalação.

$ yay -S oksh

Basta confirmar e a instalação irá iniciar!

Se for outra distro, instale o oksh com o gerenciador de pacotes dela. Pode também instalar o oksh direto do código fonte:

Instalando o oksh via código fonte

Muitas pessoas pensam em algo difícil quando se fala em compilar. Na verdade, o processo é bem simples!

Primeiro, precisaremos clonar o repositório do oksh. Entre no diretório em que você se sente confortável para realizar a operação e clone o repositório com o seguinte comando:

$ git clone https://github.com/ibara/oksh.git

Após a clonagem, entre no diretório criado pelo git:

$ cd oksh

Configure a compilação com o script que está dentro do repositório clonado:

$ ./configure

E depois compile:

$ make && sudo make install

Tente aliviar a sua máquina de programas abertos sem motivos ou que consomem muito de seu processador, compilar vai usar bastante a sua CPU.

Configurando o oksh

Com o shell já instalado, precisamos configurá-lo! Para isso, crie o seu .kshrc na sua home:

$ touch ~/.kshrc

O touch é um comando importante! Se quiser ver outros comandos que possam te ajudar na sua jornada no mundo Linux, temos um artigo dos 10 principais comandos para iniciantes no Linux!.

Agora que já temos um arquivo de configuração, basta configurá-lo de acordo com sua preferência. Mas para que não haja muitos dúvidas, aqui está um exemplo de .kshrc, o mesmo demonstrado no print anterior.

Temos um .kshrc configurado e funcionando. Agora precisamos setar o nosso arquivo de configuração para nosso shell. Para isso, vamos criar um .profile na home de usuário:

$ touch ~/.profile

Dentro do arquivo criado, vamos adicionar uma única linha:

export ENV="$HOME/.kshrc"

Agora já está quase tudo pronto, basta adicionar o /usr/bin/oksh no shells. Para fazer isso, dê o seguinte comando e siga o passo seguinte:

$ sudoedit /etc/shells

Se aparecer um erro dizendo: sudoedit: /usr/bin/vi: comando não encontrado, basta instalar o vi e executar o comando novamente. Já se você prefere não utilizar o vi, recomendo que leia esse trecho de um artigo da Arch Wiki que ensina a mudar o editor do sudo.

Se o erro não aparecer, entraremos em outra bifurcação… Se você instalou a partir do código fonte, adicione as seguintes linhas:

/usr/local/bin/oksh

Se a instalação foi por repositório ou pelo AUR, adicione as seguintes linhas:

/bin/oksh
/usr/bin/oksh

Vai ficar mais ou menos assim:

Para salvar e sair do arquivo, pressione a tecla ESC e depois digite :wq. Pressione enter e o arquivo estará salvo.

Depois, basta dar o comando abaixo e reiniciar seu usuário:

$ sudo chsh -s /usr/bin/oksh $USER

Por fim, encerre sua seção e inicie novamente. Pronto! Você já pode usar seu oksh!
